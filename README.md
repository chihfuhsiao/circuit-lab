# 電路實驗室

給高中資訊科、電子科學生使用的電路模擬軟體。可以在電路圖或麵包板上接線，即時模擬類比與數位電路。

- 電路圖與麵包板兩種畫面，麵包板導通規則與實體相同
- 示波器、三用電錶、電源供應器、訊號產生器
- 21 個內建範例、9 個引導實驗（每一步自動檢查）
- 深色與淺色主題
- 不需要帳號、不收集資料，可離線使用

## 使用

打開網頁就能用：https://chihfuhsiao.github.io/circuit-lab/

也可以自己打包成單一檔案：

```bash
npm install
npm run build
```

產生的 `dist/index.html` 是單一檔案，雙擊就能開，也可以放到 USB 或校內共用資料夾。

開發時用 `npm run dev`，測試用 `npm test`。
