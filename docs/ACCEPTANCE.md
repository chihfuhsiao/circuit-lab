# 電路模擬軟體 驗收清單

> **自動**＝`npm test` 或瀏覽器實測已驗證；**你**＝需要你實際操作才能判斷。
> 開啟方式：雙擊 `dist/index.html`；開發中用 `npm run dev`。

## 只有你能判斷（請優先試）
- [ ] **介面外觀**：新外觀合不合你想要的感覺；預設深色好不好，或要改成預設淺色（「檢視」功能表或右上角可以切換）
- [ ] **網頁版**：開 https://chihfuhsiao.github.io/circuit-lab/ 能不能用，分享連結傳給別人打不打得開；學校網路會不會擋 github.io
- [ ] **雙擊開啟**：直接雙擊 `dist/index.html` 能不能用（只在瀏覽器窗格用靜態方式測過，沒有真的從檔案總管雙擊）
- [ ] **動畫順不順**：電流動畫、示波器、555 閃爍的流暢度（測試時窗格隱藏，動畫是手動推進的，沒有親眼看過連續播放）
- [ ] **操作手感**：拉線、插元件、拖引腳；麵包板的孔會不會太小難點
- [ ] **存檔與開啟**：實際存一個檔再開回來（存檔格式已自動測試，但沒有按過瀏覽器的下載與選檔視窗）
- [ ] **教學內容**：9 個實驗的步驟與用語、問答的難度、範例夠不夠貼近課本
- [ ] **符號與慣例**：電路符號、腳位標示和你們用的課本是否一致
- [ ] **學校環境**：電腦教室的瀏覽器版本、投影時字夠不夠大
- [ ] **平板觸控**：版面看過，但沒有用真的觸控操作過

## 待你決定
- [ ] `docs/DECISIONS.md` 標〔待確認〕的項目：電路圖與麵包板的關係、視覺外觀、錯誤回饋方式、軟體名稱。

## 已自動驗證
- **數值**：分壓、歐姆定律、惠斯登電橋、疊加、RC、RL、LC 共振、RLC 諧振、二極體、半波與全波整流、濾波、齊納、LED、NPN、PNP、NMOS、PMOS、反相與非反相放大、削波、比較器、史密特振盪、電錶各檔位。
- **數位**：各閘真值表、輸入空接、SR 拴鎖、環形振盪器、D 與 JK 正反器、計數器、7400、7474、7493、555 週期、VCC 過壓燒毀。
- **異常**：短路、電源並聯、懸空節點都不會當掉。
- **接線**：T 型接點、交叉不相連、接地同一點、麵包板導通規則、DIP 腳位、對照電路圖（少接、多接、未放置）。
- **內容**：21 個範例接線完整且不出錯；9 個實驗的參考電路通過檢查、空白電路不會過關。
- **瀏覽器實測**（真實滑鼠事件）：見 `docs/PROGRESS.md` 驗證紀錄。

## 尚未自動驗證
- 畫面操作沒有自動化測試，都是手動在瀏覽器走過一次；之後改編輯器要再手動確認。
- 實驗的中間步驟（例如改電阻值、切換開關）只有部分用滑鼠走過；自動測試只檢查標 `final` 的步驟。
- Firefox、Safari 沒有測過。
