# 電路模擬軟體 已知問題／限制

> 修改相關功能前搜尋本檔；修好時把該項移到 docs/PROGRESS.md 並註明日期。

## 功能尚未做
- 沒有複製貼上；導線只能刪除重拉，不能拖曳線段調整走向。
- 只有時域模擬（示波器），沒有頻率響應圖（波德圖）。
- 沒有自動排到麵包板，學生要自己插（這也是教學目的，但老師備課可能想要）。
- 實驗進度只存在記憶體：重新整理頁面後電路還在，但步驟要從頭開始。

## 模型限制
- 運算放大器的輸出電流由接地回流，不經過 V+、V− 腳，所以電源的電流讀值會偏小（輸出與節點電壓不受影響）。
- 電晶體沒有 Early 效應與頻率限制；運算放大器沒有迴轉率與增益帶寬限制，高頻下比實際元件理想。
- 74 系列用行為模型：輸入內部上拉、輸出是固定電阻，傳遞延遲是 1～2 個模擬步長，不是實際的奈秒級延遲。
- 步長固定，訊號頻率相對模擬速度太高時波形會失真（會顯示提醒，要學生調慢）。
- 起始狀態一律從 0 開始（電容未充電），沒有先解直流工作點，所以放大電路要等偏壓建立。範例已調小電容來縮短等待。

## 麵包板
- 電路圖的邏輯閘符號與麵包板的 IC 無法逐腳對照，「對照電路圖」會列為略過。
- 七段顯示器的實體間距簡化成跨在中央溝槽上，和實際 0.6 吋包裝不同。
- 電源軌視為整排相通，實際部分麵包板的電源軌中間是斷開的。
- 電流動畫只畫在跳線上，元件本體內沒有。

## 介面
- 只有淺色主題。
- 視窗大小改變時畫面不會自動重新對準，要按「全部顯示」。
