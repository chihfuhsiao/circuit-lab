# 電路模擬軟體 已確定的設計決定

> 修改某功能前用 Grep 搜尋相關小節。除非使用者明確要求，不要更動；標〔待確認〕的項目不可自行判斷刪改。

## 使用者與定位（2026-11-02 使用者決定）
- 主要使用者：高中資訊科、電子科學生。兩科都要顧到：資訊科偏數位邏輯，電子科還需要類比。
- 課程對應：基本電學、電子學、數位邏輯設計。
- 特色：繁體中文、貼近課本、免帳號、免安裝。

- 軟體名稱暫定「電路實驗室」（2026-11-02 Claude 提出）〔待確認〕。

## 模擬範圍（2026-11-02 使用者決定）
- 類比＋數位都做，放在同一個引擎，可以混合（例如類比振盪接數位計數器）。
- 精確度以教學為準：數值要正確、趨勢要清楚，不追求工程級的元件模型。

## 接線畫面（2026-11-02 使用者決定）
- 電路圖＋麵包板都做。

### 兩種畫面的關係（2026-11-02 Claude 提出）〔待確認〕
- 兩個畫面**共用元件清單**（同一個 R1），**接線各自獨立**。學生對照電路圖在麵包板上接線，和實習課的流程相同。
- 模擬的是**目前畫面**接出來的電路；沒放到目前畫面的元件不參與模擬。
- 麵包板提供「對照電路圖」：逐項指出哪些腳少接、哪些腳多接。
- 數位元件：電路圖用邏輯閘符號（隱含 5V 電源，一個閘一個元件）；麵包板用 74 系列 IC（要實際接 VCC、GND，一顆內含多個閘）。兩者無法逐腳對照，改用行為檢查（真值表）。
- 接地符號、電源標籤只存在於電路圖；麵包板以電源供應器的負極當參考點。

## 教學功能（2026-11-02 使用者決定）
- 自由接線的沙盒＋內建範例＋引導實驗（步驟說明、自動檢查電壓電流是否達標）。
- **不做**班級系統（派題、繳交、成績），避免後端、帳號與個資問題。

## 技術路線（2026-11-02 使用者決定）
- 純前端網頁＋TypeScript＋Vite；打包成單一 HTML 檔，雙擊可開。
- 另外提供網頁版，開網址就能用，和土管查詢一樣放 GitHub Pages（2026-11-02 使用者決定）。

## 視覺外觀
- 外觀要接近目前的商業軟體，不要太陽春（2026-11-02 使用者要求）。
- 版面仿專業工程軟體：功能表＋工具列＋畫面分頁＋可拖曳的面板＋狀態列（2026-11-02 Claude 提出）〔待確認〕。
- 預設深色，另有淺色主題給教室投影使用；麵包板維持白色，放在深色桌面上（2026-11-02 Claude 提出）〔待確認〕。

## 版本控管（2026-11-02 使用者決定）
- 用 git，不再手動備份到 `_舊版備份/`。
- 遠端放 GitHub，歷史的備份靠它，因為 Synology Drive 不同步 `.git/`。
- repo 公開，但保留所有權利，不放授權條款；commit 用 GitHub 隱藏信箱，不露出個人信箱。

## 實作預設（2026-11-02 Claude 提出，使用者未反對）
- 模擬引擎自己寫，採修正節點分析法（MNA）＋牛頓法，理由：拖曳時能即時更新、邏輯閘能放進同一引擎、不必帶龐大的外部程式。
- 不做帳號；存檔用 JSON 檔案，分享用檔案或連結。
- 介面繁體中文，符號跟課本一致。

## 錯誤回饋（2026-11-02 Claude 提出）〔待確認〕
- 短路、元件燒毀、線沒接好，都用學生聽得懂的話說明，並指出是哪個元件。
- LED 電流過大會燒毀（要按「重設」才恢復），讓學生體會限流電阻的必要。
- 計算不收斂時不可卡住畫面：繼續執行並顯示提醒。
